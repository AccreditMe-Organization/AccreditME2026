Deleted files go to a 30-day recycle bin. Tweaks switch the full English page through every state and the usage panel through its four cases.

The limit counts AccreditMe cloud only. On your own storage the panel shows files and size there, with “Your own storage: no AccreditMe limit applies” and no meter, so nobody reads it as a gauge. Files still in AccreditMe cloud from before get one line against the limit. Near the limit (from 90%) the fill is amber and hatched with “Almost full”; at the limit it's solid red with the consequence spelled out. Raising the limit is plain text, “Contact AccreditMe to raise the limit.”, because only AccreditMe changes a plan.
